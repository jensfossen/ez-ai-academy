# Models landscape — optional formative check

## How to use this

Use **at most this one check**, after a teaching or example moment in `curriculum/models-landscape.md`. This is a conversation, not a mini-exam. Do not display point values or a letter grade.

This check is **optional**. Skip it on the short path unless the learner asks. It is **not** completion evidence. Do not invent a second check, an exercise bank, or a rubric for this companion.

Stay inside companion vocabulary: `model`, `model name`, `family`, `maker` / `company`, `version`, `workplace tool` / `the AI at work`, `official page`, plus Module 1’s `request`, `check`, and pattern-based predictor. Do not introduce tokens, Elo, “the best model,” catalogs, agents, or harnesses.

Interpret each choice on a four-level scale:

- **3 — Best:** captures the central idea and a sound working habit.
- **2 — Reasonable:** useful, but misses an important distinction.
- **1 — Partial:** contains a small truth but could create a misleading mental model.
- **0 — Misconception:** conflicts with the core idea.

After the learner answers, first name what makes the choice understandable. Then explain why the highest-quality choice is stronger. Move to wrap-up or Prompt Engineering; do not immediately ask another check.

Default content owner for this key: Academy coordinator / Professor Devy (`resources/asset-governance.md`).

## Check A — Reading an assigned name

**render_intent:** `native_choice_card` — Use the host ask questions tool when the host attaches it (single-select). Prefer that over typing the A–D list as plain text. If the tool is missing, show the numbered A–D list and accept a letter, number, or natural-language answer. Do not put host-specific markup in the question text. Mentors: `ui/interaction-patterns.md` (Knowledge check).

**Question:** A coworker writes, “Use Nova Lite for this draft — our AWS team assigned it.” What is the best way to think about that name?

- **A.** You should memorize every Nova edition before you start the draft. `0`
- **B.** Amazon is the maker, Nova is the family, and Lite is an edition hint — still give a clear request and check the draft. `3`
- **C.** Lite means a different company built it, so you should switch tools. `0`
- **D.** The assigned workplace tool is enough; the words after Nova do not matter. `2`

**Coach:** B is strongest because it reads maker, family, and edition hint, stays with the assigned tool, and keeps Module 1’s check habit. D is reasonable: the workplace already chose the tool, so catalog-watching is not required — but the extra word is still a useful hint, not noise. C treats an edition word as a new maker. A turns a label into homework.

**Source basis:** Amazon’s official Nova overview presents Nova as Amazon’s own model family on AWS, with extra words marking editions of that family — not a different company. The Academy’s companion rule: read maker + family + extra words; still check important output. Do not cite a catalog, price, or rank.
