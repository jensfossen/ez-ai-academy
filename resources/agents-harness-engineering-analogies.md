# Module 4 Analogy Cards

Use one or two cards at a time. An analogy is a bridge into the idea, not a complete technical definition. Always pair the helpful comparison with its limit.

If this file is missing (Cowork ZIP), use the analogy already written in the current lesson in `curriculum/agents-harness-engineering.md`.

Stay inside Module 4 vocabulary: `agent` / goal-seeking helper, `harness` / the setup around the model, `tools`, `rules`, `memory`, `files`, `interface` / how you talk to it, and `permission` / what it may do. Do not introduce loops, GraphRAG, frameworks, windows, or tokens.

## Recommended starting language

**An agent is a goal-seeking helper that can take steps. A harness is the workplace setup around the model.** A chat box with no tools is still a harness — it just has few permissions.

This is the default Module 4 mental model. A clearer request does not repair extra send-email. A current pack does not replace a missing rule.

## A coworker and their badge

**Simple version:** The coworker you send to get a signature is the helper. The badge, keys, and desk rules are the harness.

**What it explains:** A visitor badge with no keys is still a harness. Few permissions is still a setup.

**Where it breaks:** When there is no person to send — a chat box still wraps the model.

## A spare-key drawer

**Simple version:** You do not hand every key for a one-room errand.

**What it explains:** Tools are what the helper may use. Permission is what it may do. More access is not a better harness.

**Where it breaks:** When a locked door *is* the job — then that key is needed.

## Kitchen rules on the wall

**Simple version:** Rules stay posted on the wall. You do not rewrite them on every sticky note.

**What it explains:** Standing limits live in the harness. Today’s wording is still Prompt Engineering.

**Where it breaks:** When today’s dish needs a special instruction — that is this request, not a wall rule.

## A labeled inbox

**Simple version:** A labeled inbox is what the helper may keep. Dumping the filing room on the desk is not safer.

**What it explains:** Memory is standing notes you chose. Files are which folders it may open. Today’s pack is still Context Engineering.

**Where it breaks:** When today’s pack is the only thing that matters — then you are back in Module 3, not standing memory.

## A walk-up window

**Simple version:** The same kitchen through a walk-up window versus a pass to the storeroom. The window is the interface.

**What it explains:** If the soup is wrong, check the order (request), the ingredients (pack), or the keys (harness) before you write a longer note.

**Where it breaks:** When you start scoring every batch to redesign the recipe. That measured cycle is Loop Engineering — still upcoming.

## Mentor prompt

After showing two analogies, ask:

> “Which comparison would help a coworker remember that a chat box is already a setup—and where does that comparison stop being accurate?”

Accept a new learner-created analogy when it preserves the two central ideas: the helper is not the same as the setup, and a weak result can come from the wrong tools, rules, memory, files, or interface.
